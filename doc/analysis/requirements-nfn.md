# Requisitos No Funcionales
---

## Alta Prioridad

RNF-01: El sistema deberá implementar autenticación de usuarios mediante correo electrónico y contraseña, garantizando el almacenamiento seguro de las credenciales.

RNF-02: La aplicación deberá asegurar que toda la comunicación entre el cliente móvil y el servidor se realice mediante protocolos seguros.

RNF-03: La aplicación deberá responder a las acciones del usuario en un tiempo menor o igual a 3 segundos en al menos el 80% de las interacciones bajo condiciones normales de uso.

RNF-04: El sistema deberá manejar fallos comunes, como pérdida de conexión o errores del servidor, sin provocar cierres inesperados de la aplicación.

---

## Prioridad Media

RNF-05: El sistema deberá estar disponible para su uso durante la mayor parte del tiempo académico, permitiendo interrupciones controladas por mantenimiento.

RNF-06: La aplicación deberá ofrecer una interfaz clara e intuitiva que permita a los usuarios comprender y utilizar las funcionalidades principales sin necesidad de capacitación previa.

RNF-07: La aplicación deberá seguir buenas prácticas básicas de accesibilidad, incluyendo tamaños de texto legibles, contraste adecuado y compatibilidad con lectores de pantalla.

RNF-08: El sistema deberá permitir la incorporación futura de nuevas funcionalidades sin requerir cambios significativos en su arquitectura.

---

## Baja Prioridad

RNF-09: El proyecto deberá contar con una estructura de código clara y documentación básica que facilite el mantenimiento y la comprensión del sistema.

RNF-10: La aplicación deberá ser compatible con dispositivos Android e iOS que ejecuten versiones actuales o recientes de sus sistemas operativos.
