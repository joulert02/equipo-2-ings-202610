# FavUPB

Este repositorio contiene el desarrollo de FavUPB, una aplicación móvil construida con React Native orientada a la gestión de favores bajo demanda dentro del entorno universitario. Aquí se encuentra el código fuente de la aplicación, junto con la estructura de componentes, vistas y lógica de negocio necesarias para permitir la publicación, aceptación y seguimiento de solicitudes de favores entre usuarios.

El proyecto incluye la implementación de interfaces móviles, navegación entre pantallas, manejo de estado, modelos de datos y servicios requeridos para soportar funcionalidades como creación de solicitudes, visualización de pedidos disponibles, aceptación de favores y registro de remuneraciones. También se documentan las decisiones técnicas, la arquitectura del proyecto y las instrucciones de instalación y ejecución para entornos de desarrollo.

Además del código de la aplicación, el repositorio contiene documentación técnica, guías de configuración y recursos de apoyo utilizados durante el proceso de diseño e implementación.
